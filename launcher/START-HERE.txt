COURSE NOTEBOOKS - HOW TO INSTALL AND START THEM
================================================

You install the course tools ONCE by pasting one line into a window where you can type. After that you only double-click.
Nothing is downloaded with your browser, so your computer shows no security warnings.


INSTALLING (ONCE)
-----------------
1. Open the window where you can type:
     Mac:      press Cmd + Space, type  Terminal  and press Enter.
     Windows:  open the Start menu, type  PowerShell  and press Enter.
2. Copy the line for your computer from the course page (or from here), paste it into that window and press Enter.
     Mac:      Cmd + V pastes.
     Windows:  a right-click pastes.

   MAC
     curl -fsSL https://github.com/alvarobernal2412/hs-marimo26/releases/latest/download/install.sh | bash

   WINDOWS
     powershell -ExecutionPolicy Bypass -c "irm https://github.com/alvarobernal2412/hs-marimo26/releases/latest/download/install.ps1 | iex"

3. Wait. It downloads the course tools into a folder called  hs-marimo26  in your home folder, and starts them.
   The very first time it says "Setting up the course tools" and takes a few minutes. Keep the window open.
4. Then two pages ask you something, once:
     - whether your analyses may be shared with the course (see "Sharing your analyses" below);
     - the course code, to download the course event log (see "The course code" below).
   After that your browser shows the list of notebooks. Click the one you need.

Only the first step needs the typing window. From now on, you start the notebooks like this:


STARTING (EVERY TIME)
---------------------
Open the folder  hs-marimo26  in your home folder and double-click "Start"
(Start.bat on Windows, Start.command on a Mac). It starts in a few seconds.

Keep the window that opens while you work. Closing the window stops the notebooks.
Closing the browser tab does NOT stop them: double-click Start again and the tab comes back.


STOPPING, AND STARTING AGAIN
----------------------------
To stop:   close the window that opened when you started (the browser tab can stay or go).
To start:  double-click Start again. It is always safe to double-click it again, at any time:
             - if the notebooks are not running, it starts them;
             - if they are already running, it just opens the page again;
             - if the first setup was cut short, it finishes it (see below).
Your work is saved as you go, so you lose nothing when you stop.


IF YOU CLOSE THE LAPTOP, IT GOES TO SLEEP, OR IT SHUTS DOWN
-----------------------------------------------------------
- Sleep, or lid closed: the notebooks just pause. When you wake the laptop, reload the page in your browser.
  If the page still says it is disconnected: close the window, then double-click Start again.
- Shut down, restart, battery empty, or a crash: the notebooks are gone, nothing keeps running in the background.
  Double-click Start again.
- This also holds in the middle of the first setup. Nothing is broken: double-click Start again and it
  finishes the setup (it may start the setup over, so allow a few minutes again). Please do not open Start twice
  at the same time while the very first setup is running.


THE COURSE CODE
---------------
The two assignment notebooks work on an event log that is not public, so it is not part of what you installed.
The first time you start, a page asks for the course code your teachers gave you (the same code for everyone)
and downloads the event log to this computer. You do this once.
- "Not now", or no internet: the notebooks still start. The two lecture notebooks work; the two assignment
  notebooks tell you that the event log is missing. Double-click Start again and the page comes back.
- Please do not pass the event log or the course code on to anyone outside the course.


YOUR KEY
--------
If you share your analyses (see below), "01 Assignment - Initial Analysis" and "03 Assignment - Process Map" ask for
your personal key. Paste it once. Your work is saved under it and comes back whenever you use the same key, on any computer.
The key is not the course code: the course code is the same for everyone, the key is yours alone.


SHARING YOUR ANALYSES (OPTIONAL)
--------------------------------
The first time you start, a page asks whether your analyses may be shared with the course, anonymised:
only the analysis steps you run, not your clicks. They are used to improve the course and for research on tools
that support exploratory analysis. You answer once and are not asked again. If you say no, everything works the
same; your work just stays on your computer.

To change your answer: double-click "Change-my-answer" (Change-my-answer.bat on Windows, Change-my-answer.command
on a Mac, next to Start). If the notebooks are running, close their window first. The page then asks again.


REMOVING EVERYTHING
-------------------
To remove the course tools and your saved work from this computer, double-click "Uninstall" (Uninstall.bat on Windows,
Uninstall.command on a Mac, next to Start). Close the notebooks' window first. It shows what will be deleted and what that
means for your work, and goes ahead only when you type YES.
- If you shared your analyses with the course server, that copy stays there: Uninstall does not remove it. Enter the same key
  after a new setup and your work comes back. Ask your teachers if you want the server copy deleted too.
- If you did not share them, they exist only on this computer and are lost for good.
- The course event log is removed too. After a new setup you enter the course code again.
- The folder  hs-marimo26  with Start in it stays: delete it yourself when you no longer need it.


IF SOMETHING GOES WRONG
-----------------------
- The pasted line says it could not find the latest version, or the download did not work: check your internet
  connection and paste the line again. It is safe to paste it as often as you like.
- A red message ("Failed to fetch", "Unauthorized", lost connection), or a page that does not respond:
  reload the page. Your work comes back as you left it. If the key is asked again, paste it again.
- "Access is denied", or it will not start, on a laptop managed by your university: the laptop's security
  policy can block a new program. Ask your IT department to allow this folder:
    Windows: %LOCALAPPDATA%\hs-marimo26
    Mac:     ~/Library/Application Support/hs-marimo26
  Nothing in it needs administrator rights.
- An assignment notebook says "The course event log is not on this computer yet": close the window, double-click
  Start again and enter the course code. "That is not the course code": check for a missing character or a space,
  or ask your teachers.
- "This Mac runs macOS ... The course tools need macOS 12 (Monterey) or later": update macOS
  (Apple menu > System Settings or System Preferences > Software Update) and paste the line again.
- Still stuck? Take a photo of the window and send it to your teachers.


UPDATES
-------
Each time you start, the notebooks fetch the latest version by themselves when you are online.
Only if the window tells you that a new package is needed, paste the install line above once more.


THE EVENT LOGS
--------------
They are in the "notebooks/data" folder inside the folder the course tools were set up in:
  Windows: %LOCALAPPDATA%\hs-marimo26\runtime\notebooks\data
  Mac:     ~/Library/Application Support/hs-marimo26/runtime/notebooks/data
- Purchasing-Example.csv and SepsisCases2020EventLog.xes: the public logs of the lecture notebooks.
- The course event log of the assignments (a .parquet file), once you have entered the course code.
